# DataEntry

📊 End-to-End Data Entry Workflow Using Excel, Python, and MySQL

This project demonstrates a complete data entry and processing pipeline that integrates manual data input, automated validation, data cleaning, ETL processes, error logging, and data quality assurance using Excel, Python, and MySQL.

The workflow simulates real-world scenarios where raw data originates from unstructured documents and must be manually entered into Excel before being processed through an automated data pipeline.

🚀 Project Overview

The pipeline consists of the following stages:

Manual data entry from document-based sources into Excel

Automated data ingestion using Python

Data validation with rule-based error detection

Error logging for quality monitoring

Automated data cleaning and transformation

ETL pipeline to load cleaned data into MySQL

Data quality assurance reporting
