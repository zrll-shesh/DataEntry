# End-to-End Data Entry Workflow Using Excel, Python, and MySQL

This project demonstrates a complete end-to-end data entry and processing workflow that integrates manual data input from document-based sources into Excel with automated data validation, cleaning, ETL pipeline execution, error logging, and data quality assurance using Python and MySQL. The workflow simulates real-world operational environments where raw information is often collected in unstructured document formats and must be manually converted into structured spreadsheets before further processing.

Once the data is entered into Excel, the dataset is ingested into Python for rule-based validation to detect inconsistencies, missing values, and out-of-range entries. All detected issues are recorded in an error logging system to enable monitoring and auditing. The pipeline then performs automated data cleaning and transformation to improve data consistency and reliability. The cleaned dataset is processed through an ETL pipeline and loaded into a MySQL database as a structured storage layer for downstream use.

To ensure reliability and accuracy, a data quality assurance module generates summary metrics such as total records processed, error counts, cleaned records, missing values, and duplicate detection. This project highlights practical implementation of manual data entry workflows combined with automated data processing, scalable ETL design, and systematic data quality control, reflecting common practices in data engineering and analytics pipelines.
